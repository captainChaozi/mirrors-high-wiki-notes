## Launch-month essentials
- Claim Gifts before starting story.
- Use the free ★4 retry summon, but decide a stop condition first.
- Teams are three characters: one main attacker, one debuffer (Chain/Shadow types such as Mayuri, Orihime, Byakuya), one flexible slot.
- Aizen Launch Banner (PICKUP #1) ends 2026-11-24 05:59 UTC / 14:59 JST — Aizen 1.5%, 200-medal exchange.
- As of 2026-10-29 there are no verified universal redeem codes; invite codes are not redeem codes.
- Link a Bandai Namco ID before changing devices.
